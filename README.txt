CONCURSUL DE CRĂCIUN – SITE PENTRU GITHUB PAGES

Fișiere:
- index.html
- style.css
- script.js

PUBLICARE:
1. Creează un repository nou pe GitHub (de exemplu: concurs-craciun).
2. Încarcă toate cele 3 fișiere în rădăcina repository-ului.
3. Intră la Settings -> Pages.
4. La "Build and deployment", alege "Deploy from a branch".
5. Selectează branch-ul "main" și folderul "/ (root)", apoi Save.
6. După publicare, GitHub îți va afișa adresa site-ului.

COD QR:
Codul QR de pe afiș trebuie să conțină adresa finală GitHub Pages.
După ce site-ul este publicat, copiază aici adresa primită și generează un QR nou
care să trimită exact la acea adresă. Nu folosi un cod QR provizoriu sau unul desenat,
deoarece nu va deschide site-ul.
